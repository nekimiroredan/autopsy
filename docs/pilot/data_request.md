# Pilot data request

- Export 8–12 weeks of warehouse movements. Include timestamp, item, location, signed quantity or separate in/out quantities, and event type.
- Export physical counts with timestamp, item, location and counted quantity. Include at least two counts for each item and location where possible.
- Include transaction and count IDs where available. Document numbers, worker IDs, shifts and an item master help verify more causes. Item master fields include unit cost, pack size, similar item group and location zone.
- Replace sensitive identifiers with stable pseudonyms. Remove customer and employee names.
- Send CSV or XLSX. Keep the original export column names and formats.
